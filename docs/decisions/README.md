# Decisions

One file per lasting decision about Garage. Planning and coding agents read the index below before proposing or
changing behavior; humans read it to see why Garage is the way it is. Format and process:
[design-step.md](../design-step.md) section 5.

- Name: `YYYY-MM-DD-short-name.md`. The name without `.md` is the decision's id.
- Front matter: `status` (proposed | accepted | superseded | rejected), `date`, `decided_by`, `scope`
  (project | workspace), `areas`, optional `issue`, `design`, `pr`, `supersedes`, `superseded_by`.
- Body: Question, Options considered, Decision, Why, What this rules out / revisit when. Keep it under ~40 lines.
- Never delete a record. To change a decision, add a new one with `supersedes:` and mark the old one `superseded`.

The first records were backfilled on 2026-11-08 from earlier PRs and sessions; their dates are when the decision
was first written down, as best known.
